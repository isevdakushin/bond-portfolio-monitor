# Анализ портфеля еврооблигаций

Инструмент для повторяемого анализа портфеля еврооблигаций: загрузили файл портфеля → получили проверку
качества данных, аналитику, рыночный фон из официальных источников, сигналы, правила добора, сравнение
с прошлым снимком и отчёт на 1–2 страницы.

**Приложение:** https://bond-portfolio-monitor.streamlit.app — загрузите файл портфеля (.xlsx/.xls/.csv) в боковой
панели; шаблон файла и требования — там же, во вкладке «Методология и инструкция».

## Что умеет

| Вкладка | Что показывает |
|---|---|
| 1. Качество данных | расхождения в файле: веса, даты погашения, рейтинг/bucket, дюрация, ISIN, итоги дашборда |
| 2. Аналитика | YTM (брутто и после комиссии), дюрация, G-spread против целей; аллокация; концентрации; распределения |
| 3. Рыночные данные | кривая UST (U.S. Treasury) и HY OAS (FRED) на дату снимка и последнюю дату, с источниками |
| 4. G-spread | независимый пересчёт G-spread по кривой Treasury и сверка с файлом |
| 5. Сигналы по спредам | бумаги со спредом шире пиров того же рейтинга и дюрации; аномальные расширения между снимками |
| 6. Правила добора | правила стратегии из файла (лестница 10Y UST, триггер HY OAS, календарь) против рынка → действия |
| 7. Сравнение снимков | изменения метрик, аллокации, бумаг и рейтингов; разложение изменения доходности |
| 8. Оценка и стресс | оценка портфеля на сегодня по индексам ICE (FRED); стресс-тест UST ±100 бп и спредов EM/HY |
| 9. Отчёт | записка на 1–2 страницы (HTML, печать в PDF); каждое число — из расчёта |

Подробно — во вкладке «Методология и инструкция» или в [docs/METHODOLOGY.md](docs/METHODOLOGY.md):
требования к файлу, формулы, допущения с обоснованием, источники и ограничения.

## Правило данных

- Данные по бумагам — только из файла компании; рыночный фон — только U.S. Treasury и FRED, с датой и ссылкой.
- Производные метрики — только расчётом; формулы — в методологии.
- Пороги — допущения со значениями по умолчанию и обоснованием в [config.yaml](config.yaml); меняются в интерфейсе.
- Бесплатных источников цен по отдельным еврооблигациям нет: доходности и спреды бумаг — из файла компании.
- Решение остаётся за аналитиком.

## Запуск локально

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\streamlit run app.py
```

Без интерфейса (результаты — в `output/`):

```bash
.venv\Scripts\python run_report.py Портфель_новый.xlsx --previous Портфель_прошлый.xlsx
```

Ключ FRED (бесплатный, https://fredaccount.stlouisfed.org) — в файле `.env` (см. `.env.example`) или в Secrets
Streamlit Cloud как `FRED_API_KEY`. Без ключа данные FRED загружаются медленнее через CSV-выгрузку.

## Структура

- `core/` — ядро расчётов, не зависит от интерфейса (загрузка, проверки, аналитика, рынок, G-spread, сигналы,
  правила, сравнение, оценка, стресс, отчёт).
- `app.py`, `ui_*.py` — интерфейс Streamlit.
- `run_report.py` — запуск скриптом.
- `tests/` — автотесты (`python -m pytest`), рыночные — на сохранённых выгрузках, без интернета.
- `samples/` — примеры файлов в других форматах; `tools/` — генерация примеров и документации.

Python 3.12.

Файл портфеля компании и примеры, сделанные из него, в репозиторий не входят (данные компании).
Тесты на реальном файле пропускаются, если его нет; положите файл в корень проекта, чтобы их запустить.
